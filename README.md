# Sales Dashboard - Excel

## Project Overview
This project is an interactive Excel Sales Dashboard designed to analyze sales performance and provide actionable business insights.

## Business Problem
Businesses need a simple way to monitor sales performance, identify top-performing products, and track regional trends.

## Dataset
- Sales transactions
- Products
- Regions
- Customers
- Revenue
- Profit

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Dashboard Features
- Total Sales
- Total Profit
- Top Products
- Regional Sales Analysis
- Monthly Sales Trend

## Key Insights
- Identified the highest-performing products.
- Compared regional sales performance.
- Tracked monthly sales growth.

## Recommendations
- Focus on high-performing regions.
- Improve sales in low-performing areas.
- Increase inventory for best-selling products.
